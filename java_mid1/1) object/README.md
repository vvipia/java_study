# 📖 Chapter Summary - Object

## 핵심 내용

- java.lang은 자바에서 기본으로 제공하는 라이브러리중 가장 기본이 되는 클래스로 Object(모든 자바 객체의 부모), String(문자열), Integer/Long/Double(래퍼 타입) 등이 있음.
- java.lang은 임포트 하지 않아도 자동으로 됨.
- Object는 최상위 부모 클래스로 다른 클래스는 묵시적으로 상속 됨.
- Object 클래스가 있는 이유는 공통 기능 제공과 다형성의 기본 구현임.
- OCP 원칙 {
            Open: 새로은 클래스를 추가하고, 오버라이딩을 해서 기능을 확장할 수 있다
            Closed: 새로운 클래스를 추가해도 변경하지 않고 클라이언트 코드를 사용한다
            }
- 정적 의존관계는 컴파일 시점에 결정되며, 클래스가 어떤 타입을 사용하는지를 통해 확인할 수 있음.
- 동적 의존관계는 런타임에 실제로 어떤 객체가 전달되고 사용되는지를 의미함.
- 일반적으로 의존관계라고 표현하면 정적 의존관계를 뜻함.
- 동일성은 `==` 연산자로 두 참조가 같은 객체를 가리키는지 비교하는 것임.
- 동등성은 `equals()` 메서드로 두 객체가 논리적으로 같은지 비교하는 것임.
- `Object`의 기본 `equals()`는 내부적으로 `==`를 사용하므로 동일성 비교를 수행함.
- 객체의 특정 필드를 기준으로 동등성을 판단하려면 `equals()`를 재정의해야 함.
- 문자열 비교는 `==`가 아니라 `equals()`를 사용해야 함.
- 정확한 `equals()` 구현에는 타입 검사, `null` 검사, 필드 비교가 필요하며 IDE 자동 생성 기능을 활용할 수 있음.
- `equals()`는 반사성, 대칭성, 추이성, 일관성, `null` 비교 규칙을 지켜야 함.
- 동등성 비교가 필요한 클래스에만 `equals()`를 재정의하면 됨.
- `equals()`와 `hashCode()`는 보통 함께 재정의하여 사용함.
