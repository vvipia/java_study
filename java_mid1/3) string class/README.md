# 📖 Chapter Summary - String Class

## 핵심 내용

- 원래 String은 클래스인데 편의상 String str1 = new String("hello"); 를 String str1 = "hello" 로 해도 적용이 됨.
- String 클래스는 내부에 char 배열로 문자열을 저장하고 편리하게 메소드로 관리하게 해줌.
- 참고로 자바9 부터는 char 대신 byte 배열을 사용함.(메모리 효율을 위해)
- 원해 문자열을 더할 때는 concat()메서드를 이용해야 하지만 편의상 +를 제공
- 동일성(Identity) 비교는 == 연산자로 두 객체의 참조가 동일한 객체를 가리키고 있는지 확인.
- 동등성(Equality) 비교는 equals() 메서드로 두 객체가 논리적으로 같은지 확인
- String a = "asd" // String b = "asd" 를 == 로 비교하면 객체가 달라서 false가 나올 것 같지만, 자바에서는 같은 문자열일 경우 새롭게 만들지 않고 참조감만 넘겨 주므로 사실상 같은 객체를 가리켜 true임.
- String은 불변 객체임 -> 문자열 풀에 있는 값이 중간에 변경되면 사이드 이펙트가 발생할 수 있어서
- 주요 메서드는 찾아볼 것.
- 불변 String의 단점: 문자를 더하거나 변경할 때 마다 새로운 객체를 생성해야 함. -> 메모리 낭비
- 불변이 아닌 가변을 사용하면 불변보다 효율적임.(StringBuilder) 단, 사이드이펙트를 주의해야함
- StringBuffer 클래스 라는 것도 있음. -> 멀티 스레드에는 안전하지만 동기화 오버레드로 인해 느림.
- StringBuilder는 메서드 체인을 제공(메서드 체인: 자기 자신의 참조값을 반환해 계속 연결해서 메서드 수행)
- 오픈소스는 메서드 체이닝 방식을 주로 사용.
