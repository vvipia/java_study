# 💻 Practice 1 - Immutable MyDate

## 실습 내용

- `MyDate`를 불변 객체인 `ImmutableMyDate`로 변경함.
- 모든 필드를 `final`로 선언하고 Setter를 제거함.
- `withYear()`, `withMonth()`, `withDay()` 메서드를 구현하여 변경된 값을 가진 새로운 객체를 반환하도록 작성함.
- 날짜 변경 시 기존 객체와 새로운 객체의 상태를 비교함.

### 배운 점

- 불변 객체에서는 값을 변경하는 대신 새로운 객체를 반환하는 방식으로 기능을 구현함.
- `withXxx()` 메서드는 원본 객체를 유지하면서 일부 값만 변경한 새로운 객체를 만드는 관례임.
- 불변 객체를 사용하면 공유 참조 상황에서도 사이드 이펙트를 방지할 수 있음.
