# 📖 Chapter Summary - Immutable Object

## 핵심 내용

- 자바의 데이터 타입은 기본형과 참조형으로 나뉨.
- 기본형은 값을 복사하여 전달하므로 여러 변수가 같은 값을 공유하지 않음.
- 참조형은 참조값을 복사하므로 여러 변수가 하나의 객체를 공유할 수 있음.
- 공유된 객체의 값을 변경하면 다른 참조에도 영향을 주는 사이드 이펙트가 발생할 수 있음.
- 객체 공유 자체는 문제가 아니며, 공유된 객체의 상태를 변경하는 것이 사이드 이펙트의 원인임.
- 불변 객체는 생성 이후 내부 상태를 변경할 수 없는 객체임.
- 불변 객체는 `final` 필드를 사용하고 값을 변경하는 메서드를 제공하지 않음.
- 값을 변경해야 하는 경우 기존 객체를 수정하지 않고 새로운 객체를 생성하여 반환함.
- 불변 객체는 공유 참조로 인한 사이드 이펙트를 원천적으로 방지할 수 있음.
- 불변 객체에서 값을 변경하는 메서드는 `withXxx()` 형태의 이름을 사용하는 경우가 많음.
- `String`, `Integer`, `LocalDate` 등 자바의 대표적인 클래스들도 불변 객체로 설계되어 있음.
