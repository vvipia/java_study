# 📖 Chapter Summary - Polymorphism 2

## 핵심 내용

- 다형성을 활용하면 구체적인 클래스 대신 부모 타입이나 인터페이스만 의존하여 중복 코드를 제거할 수 있음.
- 새로운 기능이 추가되어도 변하는 부분과 변하지 않는 부분을 분리하면 유지보수가 쉬워짐.
- 추상 클래스는 직접 객체를 생성할 수 없는 부모 클래스이며, 공통 기능과 추상 메서드를 함께 가질 수 있음.
- 추상 메서드는 자식 클래스가 반드시 오버라이딩해야 하는 메서드임.
- 순수 추상 클래스는 모든 메서드가 추상 메서드이며, 다형성을 위한 규격 역할을 수행함.
- 인터페이스는 순수 추상 클래스를 더 편리하게 사용할 수 있도록 만든 기능으로 `implements`를 사용해 구현함.
- 인터페이스는 다중 구현을 지원하며, 여러 규격을 하나의 클래스에서 동시에 구현할 수 있음.
- 클래스 상속과 인터페이스 구현을 함께 사용하면 공통 기능은 상속으로, 역할은 인터페이스로 분리할 수 있음.
