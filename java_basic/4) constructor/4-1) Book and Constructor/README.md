# 💻 Practice 1 - Book Constructor

## 실습 내용

- 책의 제목, 저자, 페이지 수를 저장하는 `Book` 클래스를 구현함.
- `title`, `author`, `page`를 멤버 변수로 선언함.
- 매개변수가 없는 기본 생성자를 구현함.
- 제목과 저자만 전달받는 생성자를 구현함.
- 제목, 저자, 페이지 수를 모두 전달받는 생성자를 구현함.
- 기본 생성자에서는 제목과 저자를 빈 문자열로, 페이지 수를 `0`으로 초기화함.
- 제목과 저자만 받는 생성자에서는 페이지 수를 `0`으로 초기화함.
- 각 생성자에서 초기화 코드를 반복하지 않도록 `this()`를 사용해 모든 필드를 받는 생성자를 호출함.
- `displayInfo()` 메서드를 구현하여 책의 정보를 출력함.

### 배운 점

- 생성자 오버로딩을 사용하면 객체 생성 시 전달하는 정보에 따라 다양한 초기화 방법을 제공할 수 있음.
- `this()`를 활용하면 하나의 생성자에 실제 초기화 로직을 모아 중복을 제거할 수 있음.
- 생성자를 통해 객체가 생성되는 순간부터 필요한 초기 상태를 가지도록 만들 수 있음.
- 기본 생성자도 직접 정의한 생성자가 존재하면 필요한 경우 개발자가 직접 작성해야 함.
