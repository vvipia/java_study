# 📖 Chapter Summary - Constructor

## 핵심 내용

- 생성자는 객체가 생성되는 시점에 필드의 초기값을 설정하기 위해 사용하는 특별한 기능임.
- 생성자의 이름은 클래스 이름과 같아야 하며, 반환 타입을 작성하지 않음.
- 생성자는 `new 클래스명(...)`으로 객체를 생성한 직후 자동으로 호출됨.
- 생성자를 사용하면 객체 생성과 초기화를 한 번에 처리할 수 있고, 필수값 입력을 강제할 수 있음.
- 멤버 변수와 매개변수의 이름이 같을 때는 `this.멤버변수`로 구분하며, `this`는 현재 인스턴스 자신을 의미함.
- 클래스에 생성자가 하나도 없으면 자바가 매개변수 없는 기본 생성자를 자동으로 제공함.
- 개발자가 생성자를 하나라도 정의하면 기본 생성자는 자동으로 제공되지 않음.
- 생성자도 매개변수를 다르게 하여 여러 개를 오버로딩할 수 있음.
- `this()`를 사용하면 같은 클래스의 다른 생성자를 호출하여 중복 코드를 줄일 수 있음.
- `this()`는 반드시 생성자의 첫 번째 줄에서 호출해야 함.
