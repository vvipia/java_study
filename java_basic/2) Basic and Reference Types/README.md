# 📖 Chapter Summary - Basic and Reference Types

## 핵심 내용

- int, long, double, boolean처럼 변수에 사용할 값을 직접 넣는 데이터 타입은 기본형
- 객체나 배열과 같이 저장된 메모리 위치를 가리키는 참조값을 넣는 타입은 참조형
- 자바는 항상 변수의 값을 복사해서 대입하지만, 참조형은 위치를 가리키는 참조값만 복사
- 참조형 변수에서 아직 가리키는 대상이 없으면 null을 넣어둘 수 있음
- null은 값이 존재하지 않는다는 뜻
- 아무도 탐조하지 않는 인스턴스가 있으면 JVM의 GC(가비지 컬렉션)이 자동으로 메모리에서 제거
