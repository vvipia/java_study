# 💻 Practice 1 - ProductOrder Refactoring

## 실습 내용

- 상품 생성 로직을 `createOrder()` 메서드로 분리함.
- 주문 목록 출력 기능을 `printOrders()` 메서드로 분리함.
- 총 결제 금액 계산 기능을 `getTotalAmount()` 메서드로 분리함.
- 객체를 메서드의 매개변수와 반환값으로 전달하도록 구현함.
- 반복되는 코드를 메서드로 분리하여 중복을 제거함.

### 배운 점

- 객체의 참조값을 메서드에 전달하고 반환하는 방식을 이해함.
- 기능별로 메서드를 분리하면 코드의 가독성과 재사용성이 향상됨.
- 하나의 메서드가 하나의 역할만 수행하도록 작성하는 것이 유지보수에 유리함.
