# 💻 Practice 2 - ProductOrder User Input

## 실습 내용

- `Scanner`를 사용하여 주문 개수와 상품 정보를 입력받음.
- 입력받은 개수만큼 `ProductOrder` 객체 배열을 생성함.
- 반복문을 사용하여 상품명, 가격, 수량을 입력받고 객체를 생성하여 배열에 저장함.
- 저장된 주문 목록과 총 결제 금액을 출력하도록 구현함.
- `nextInt()` 사용 후 `nextLine()`을 호출하여 입력 버퍼를 처리함.

### 배운 점

- 사용자 입력을 객체로 생성하여 배열에 저장하는 과정을 이해함.
- 객체 배열을 활용하면 여러 데이터를 구조적으로 관리할 수 있음을 학습함.
- `Scanner` 사용 시 입력 버퍼를 처리해야 하는 이유를 이해함.
