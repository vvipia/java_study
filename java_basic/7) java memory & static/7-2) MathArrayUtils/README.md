# 💻 Practice 2 - MathArrayUtils

## 실습 내용

- 배열의 합계, 평균, 최소값, 최대값을 계산하는 `MathArrayUtils` 클래스를 구현함.
- 모든 기능을 `static` 메서드로 구현하여 객체 생성 없이 사용할 수 있도록 구성함.
- 생성자를 `private`으로 선언하여 인스턴스 생성을 방지함.
- `average()`에서 기존 `sum()` 메서드를 재사용하여 중복 코드를 제거함.

### 배운 점

- 객체 상태가 필요 없는 기능은 `static` 메서드가 적합함.
- 유틸리티 클래스는 인스턴스를 생성하지 못하도록 `private` 생성자를 사용하는 패턴을 학습함.
- 공통 기능을 메서드로 분리하면 코드 재사용성과 유지보수성이 향상됨.
