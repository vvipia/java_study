# 💻 Practice 1 - Car

## 실습 내용

- 차량 이름과 전체 구매 수를 관리하는 `Car` 클래스를 구현함.
- `name`은 인스턴스 변수로 선언함.
- 전체 차량 수를 저장하는 `totalCars`를 `private static` 변수로 선언함.
- 생성자가 호출될 때마다 차량 수를 증가시키도록 구현함.
- `showTotalCars()`를 `static` 메서드로 구현하여 객체 생성 없이 전체 차량 수를 출력하도록 구현함.

### 배운 점

- 객체마다 다른 값은 인스턴스 변수로 관리함.
- 모든 객체가 공유해야 하는 값은 `static` 변수로 관리하는 것이 적절함.
- 객체 생성 없이 사용할 기능은 `static` 메서드로 구현할 수 있음을 이해함.
