# 📖 Chapter Summary - Access Modifier & Encapsulation

## 핵심 내용

- 접근 제어자는 클래스 외부에서 필드와 메서드에 접근할 수 있는 범위를 제어하는 기능임.
- 접근 제어자를 사용하면 객체 내부 데이터를 안전하게 보호하고 잘못된 사용을 방지할 수 있음.
- `private`은 클래스 내부에서만 접근 가능함.
- `default(package-private)`는 같은 패키지에서만 접근 가능함.
- `protected`는 같은 패키지와 상속 관계에서 접근 가능함.
- `public`은 어디서든 접근 가능함.
- 클래스에는 `public`과 `default`만 사용할 수 있으며, `private`과 `protected`는 사용할 수 없음.
- 캡슐화는 데이터를 숨기고 필요한 기능만 외부에 공개하는 객체 지향 설계 방식임.
- 객체의 데이터는 직접 수정하지 않고 메서드를 통해 접근하는 것이 안전한 구조임.
- 내부에서만 사용하는 기능은 `private`으로 숨기고, 외부에서 필요한 기능만 `public`으로 공개하는 것이 좋은 설계임.
