# 💻 Practice 1 - Max Counter

## 실습 내용

- 최대값까지만 증가하는 `MaxCounter` 클래스를 구현함.
- 현재 값을 저장하는 `count`와 최대값인 `max`를 `private`으로 선언함.
- 생성자를 통해 최대값을 초기화함.
- `increment()` 메서드에서 최대값을 초과하면 증가하지 않고 안내 메시지를 출력하도록 구현함.
- `getCount()` 메서드로 현재 값을 반환하도록 구현함.

### 배운 점

- 내부 데이터는 `private`으로 숨기고 메서드를 통해서만 변경하는 구조를 학습함.
- 객체 내부에서 조건을 검사하도록 구현하면 잘못된 값 변경을 방지할 수 있음.
- 접근 제어자는 객체의 무결성을 유지하는 데 중요한 역할을 함.
