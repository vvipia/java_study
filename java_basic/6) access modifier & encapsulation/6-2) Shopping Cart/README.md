# 💻 Practice 2 - Shopping Cart

## 실습 내용

- `Item` 클래스를 생성하여 상품명, 가격, 수량을 `private` 필드로 관리함.
- 생성자를 통해 상품 정보를 초기화함.
- `getName()`과 `getTotalPrice()` 메서드를 구현함.
- `ShoppingCart` 클래스에서 최대 10개의 상품을 저장하도록 구현함.
- `addItem()` 메서드로 상품을 추가하고, 최대 개수를 초과하면 안내 메시지를 출력하도록 구현함.
- `displayItems()` 메서드에서 상품 목록과 전체 금액을 출력함.
- 전체 금액 계산은 내부 전용 메서드인 `calculateTotalPrice()`에서 처리하도록 구현함.

### 배운 점

- 객체가 가진 데이터를 사용하는 계산은 객체 내부 메서드에서 처리하는 것이 객체 지향적인 설계임.
- 외부에서는 필요한 메서드만 호출하고 내부 구현은 알 필요가 없음을 이해함.
- `private` 메서드를 사용하면 내부에서만 필요한 기능을 숨길 수 있음.
- 캡슐화를 적용하면 데이터 보호와 코드 유지보수성이 함께 향상됨.
