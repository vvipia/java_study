# 💻 Practice 3 - Payment System User Input

## 실습 내용

- `Scanner`를 사용하여 사용자로부터 결제 수단과 결제 금액을 입력받도록 구현함.
- 입력받은 값을 `PayService.processPay()`에 전달하여 결제를 진행함.
- `exit`가 입력되면 안내 메시지를 출력하고 프로그램을 종료하도록 구현함.
- `nextInt()` 이후 `nextLine()`을 호출하여 입력 버퍼에 남은 줄바꿈 문자를 처리함.

### 배운 점

- 기존 결제 구조를 변경하지 않고 사용자 입력 기능을 추가할 수 있음.
- 입력과 결제 처리 로직을 분리하면 기존 클래스를 재사용하기 쉬워짐.
- 반복문을 사용하여 사용자가 종료할 때까지 결제를 계속 처리할 수 있음.
- `nextInt()`와 `nextLine()`을 함께 사용할 때 입력 버퍼 처리에 주의해야 함.
