# 💻 Practice 2 - Payment System

## 실습 내용

- `Pay` 인터페이스에 `pay()` 메서드를 정의함.
- `KakaoPay`, `NaverPay`, `DefaultPay`가 `Pay` 인터페이스를 구현하도록 작성함.
- `PayStore`에서 결제 옵션에 맞는 `Pay` 구현 객체를 반환하도록 구현함.
- 잘못된 결제 수단이 입력되면 `null` 대신 `DefaultPay`를 반환하도록 구현함.
- `PayService`가 구체적인 결제 클래스가 아닌 `Pay` 인터페이스에 의존하도록 리팩터링함.
- 결제 성공 여부에 따라 성공 또는 실패 메시지를 출력하도록 구현함.

### 배운 점

- 결제 수단을 선택하는 코드와 실제 결제를 처리하는 코드를 분리할 수 있음.
- `PayService`가 인터페이스에 의존하므로 새로운 결제 수단이 추가되어도 핵심 결제 로직을 유지할 수 있음.
- 기본 구현 객체를 사용하면 `null` 검사 없이 동일한 흐름으로 기능을 처리할 수 있음.
- 변하는 부분을 `PayStore`에 모아두면 코드 변경 범위를 줄일 수 있음.
- 다형성을 활용하여 OCP 원칙에 가까운 구조를 만들 수 있음을 이해함.
