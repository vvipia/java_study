# 💻 Practice 1 - Multiple Message Sender

## 실습 내용

- `Sender` 인터페이스에 `sendMessage()` 메서드를 정의함.
- `EmailSender`, `SmsSender`, `FaceBookSender`가 `Sender` 인터페이스를 구현하도록 작성함.
- 각 구현체에서 메시지를 발송하는 방식을 서로 다르게 구현함.
- 여러 구현 객체를 `Sender[]` 배열에 저장하고 반복문으로 메시지를 발송함.

### 배운 점

- 서로 다른 메시지 발송 객체를 하나의 인터페이스 타입으로 관리할 수 있음.
- 같은 메서드를 호출해도 실제 객체에 따라 서로 다른 기능이 실행됨.
- 새로운 발송 방식이 추가되어도 기존 반복 처리 코드를 그대로 사용할 수 있음.
