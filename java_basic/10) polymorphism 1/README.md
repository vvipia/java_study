# 📖 Chapter Summary - Polymorphism 1

## 핵심 내용

- 다형성은 하나의 객체를 여러 타입으로 다룰 수 있는 객체지향의 핵심 개념임.
- 부모 타입은 자식 객체를 참조할 수 있으며 이를 다형적 참조라고 함.
- 부모 타입으로 참조하면 부모가 가진 기능만 사용할 수 있음.
- 자식 기능을 사용하려면 다운캐스팅이 필요함.
- 업캐스팅은 안전하여 생략 가능하지만 다운캐스팅은 런타임 오류가 발생할 수 있어 명시해야 함.
- `instanceof`를 사용하면 다운캐스팅 가능 여부를 안전하게 확인할 수 있음.
- 메서드는 오버라이딩되면 항상 자식 메서드가 우선 실행되지만, 필드는 오버라이딩되지 않음.
- 다형성은 다형적 참조와 메서드 오버라이딩이 함께 사용될 때 가장 큰 효과를 발휘함.
