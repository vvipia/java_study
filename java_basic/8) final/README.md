# 📖 Chapter Summary - Java Memory & static

## 핵심 내용

- 자바 메모리는 **메서드 영역**, **스택 영역**, **힙 영역**으로 구성됨.
- 메서드 영역은 클래스 정보와 `static` 변수 등을 저장하는 공용 공간임.
- 스택 영역은 메서드 호출과 지역 변수(매개변수 포함)를 관리하며 메서드 종료 시 함께 제거됨.
- 힙 영역은 객체와 배열이 생성되는 공간이며, 참조가 사라진 객체는 GC가 제거함.
- 메서드는 객체마다 생성되지 않고 메서드 영역에서 하나만 존재하며 모든 객체가 공유함.
- `static` 변수는 클래스가 하나만 가지고 있는 공용 변수이며 모든 객체가 함께 사용함.
- `static` 메서드는 객체 생성 없이 클래스 이름으로 바로 호출할 수 있음.
- `static` 메서드는 `static` 변수와 `static` 메서드만 직접 사용할 수 있으며 인스턴스 변수나 메서드에는 접근할 수 없음.
- 객체 상태를 사용하지 않는 유틸리티 기능은 `static` 메서드로 구현하는 것이 적합함.
