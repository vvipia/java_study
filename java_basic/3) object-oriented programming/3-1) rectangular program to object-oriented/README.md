# 💻 Practice 1 - Rectangle Object

## 실습 내용

- 절차 지향 방식으로 작성된 직사각형 프로그램을 객체 지향 방식으로 변경함.
- 직사각형의 너비와 높이를 저장하는 `Rectangle` 클래스를 생성함.
- `width`와 `height`를 멤버 변수로 선언함.
- 직사각형의 넓이를 계산하는 `calculateArea()` 메서드를 구현함.
- 직사각형의 둘레 길이를 계산하는 `calculatePerimeter()` 메서드를 구현함.
- 너비와 높이가 같은지 확인하는 `isSquare()` 메서드를 구현함.
- `RectangleOopMain`에서 `Rectangle` 객체를 생성함.
- 객체의 너비와 높이를 설정한 후 각 메서드를 호출하여 결과를 출력함.

### 배운 점

- 직사각형의 속성과 관련 기능을 하나의 클래스에 묶을 수 있음을 이해함.
- 메서드에 너비와 높이를 계속 전달하지 않아도 객체 자신의 멤버 변수를 사용할 수 있음.
- 데이터와 해당 데이터를 사용하는 기능을 함께 배치하면 코드의 역할이 더 명확해짐.
- 절차 지향 코드를 객체 지향 구조로 변경하는 기본적인 방법을 학습함.
