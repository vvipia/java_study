# 💻 Practice 2 - Bank Account Object

## 실습 내용

- 은행 계좌를 표현하는 `Account` 클래스를 생성함.
- 계좌 잔액을 저장하기 위해 `balance` 멤버 변수를 선언함.
- 입금 금액만큼 잔액을 증가시키는 `deposit(int amount)` 메서드를 구현함.
- 출금 금액만큼 잔액을 감소시키는 `withdraw(int amount)` 메서드를 구현함.
- 출금 금액보다 잔액이 적은 경우 `잔액 부족`을 출력하도록 조건문을 작성함.
- `AccountMain`에서 `Account` 객체를 생성함.
- 계좌에 `10000원`을 입금하고 `9000원`을 출금함.
- 잔액이 `1000원`인 상태에서 `2000원` 출금을 시도함.
- 출금이 거절되는 것을 확인하고 최종 잔액을 출력함.

### 배운 점

- 계좌의 잔액과 입출금 기능을 하나의 객체 안에서 관리할 수 있음을 이해함.
- 객체의 상태를 변경할 때 메서드 내부에서 조건을 검사할 수 있음.
- 출금 가능 여부와 같은 규칙을 객체 내부에 포함하면 잘못된 상태 변경을 방지할 수 있음.
- 데이터를 직접 수정하기보다 객체가 제공하는 메서드를 통해 상태를 변경하는 것이 더 안전함.
