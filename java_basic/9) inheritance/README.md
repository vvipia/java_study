# 📖 Chapter Summary - Inheritance

## 핵심 내용

- 상속은 기존 클래스의 필드와 메서드를 새로운 클래스에서 재사용하는 기능임.
- `extends`를 사용하여 부모 클래스를 상속받을 수 있으며, 자바는 단일 상속만 지원함.
- 공통 기능은 부모 클래스에 작성하고, 자식 클래스는 필요한 기능만 추가하여 코드 중복을 줄일 수 있음.
- 상속 관계의 객체를 생성하면 부모와 자식 객체가 함께 생성됨.
- 메서드 호출 시 현재 클래스에서 먼저 찾고, 없으면 부모 클래스로 올라가며 탐색함.
- 부모의 메서드를 자식에서 재정의하는 것을 메서드 오버라이딩이라 하며 `@Override`를 사용하는 것이 좋음.
- `super`를 사용하면 부모의 필드, 메서드, 생성자를 호출할 수 있음.
- 자식 클래스의 생성자는 반드시 부모 생성자를 호출해야 하며, 기본 생성자는 `super()`가 자동 호출됨.
- 접근 제어자는 상속에도 영향을 주며 `protected`는 다른 패키지에서도 상속 관계라면 접근 가능함.
- `final` 클래스는 상속할 수 없고, `final` 메서드는 오버라이딩할 수 없음.
