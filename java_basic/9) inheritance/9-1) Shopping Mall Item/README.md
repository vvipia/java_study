# 💻 Practice 1 - Shopping Mall Item

## 실습 내용

- `Item` 부모 클래스를 생성하여 `name`, `price`, `print()`, `getPrice()`를 구현함.
- `Book`, `Album`, `Movie`가 `Item`을 상속받도록 구현함.
- 생성자에서 `super()`를 사용하여 부모 필드를 초기화함.
- 각 클래스에서 `print()`를 오버라이딩하고 `super.print()`를 호출하여 공통 정보를 출력한 뒤 상품별 정보를 추가로 출력함.
- 모든 상품의 가격을 합산하여 출력하도록 구현함.

### 배운 점

- 상속을 활용하면 공통 속성과 기능을 부모에서 관리할 수 있음.
- 생성자에서도 `super()`를 사용해 부모를 먼저 초기화해야 함.
- `super.print()`를 활용하면 부모 기능을 재사용하면서 필요한 기능만 확장할 수 있음.
- 새로운 상품이 추가되어도 부모 클래스를 재사용하여 쉽게 확장할 수 있음을 학습함.
