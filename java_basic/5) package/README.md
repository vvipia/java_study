# 📖 Chapter Summary - Package

## 핵심 내용

- 패키지는 관련 있는 클래스들을 폴더처럼 분류하고 관리하기 위한 기능임.
- 클래스는 반드시 하나의 패키지에 속하며, 소스 코드의 첫 줄에 `package`를 선언해야 함.
- 같은 패키지의 클래스는 클래스 이름만으로 사용할 수 있음.
- 다른 패키지의 클래스를 사용할 때는 `import`를 사용하거나 전체 패키지 경로를 작성해야 함.
- `import 패키지명.*`를 사용하면 해당 패키지의 모든 클래스를 사용할 수 있음.
- 같은 이름의 클래스가 여러 패키지에 존재할 수 있으며, 이 경우 하나만 `import`하고 나머지는 전체 경로를 사용해야 함.
- 패키지 이름과 실제 폴더 구조는 반드시 일치해야 하며, 패키지 이름은 소문자를 사용하는 것이 관례임.
- 일반적으로 패키지 이름은 `com.company.project` 형태로 회사의 도메인을 거꾸로 사용함.
- 패키지가 계층 구조처럼 보여도 각각은 서로 독립된 패키지이므로 필요한 경우 `import`해야 함.
- 관련 있는 클래스는 같은 패키지로 묶고, 관련 없는 클래스는 다른 패키지로 분리하여 관리하는 것이 좋음.
